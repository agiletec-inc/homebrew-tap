# Homebrew Tap for AGILE TECHNOLOGY, K.K.

```bash
brew tap agiletec-inc/tap
```

## Available Casks

| Cask | Description |
|------|-------------|
| `cmd-ime` | Switch between alphanumeric and kana using Command keys |

### cmd-ime

```bash
brew install --cask cmd-ime
```

## AIRIS Suite

AIRIS tools are no longer distributed via Homebrew. Use the unified installer:

```bash
curl -fsSL https://raw.githubusercontent.com/agiletec-inc/airis-mcp-gateway/main/scripts/quick-install.sh | bash
```
